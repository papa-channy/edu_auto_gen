### KPI
# 유저 수준 예측

- 유저의 문제 풀이 70%(임시) 정답률 유지
- 틀린 문제 30% 중 15%(절반,임시)는 현 수준으로 풀기 어려운 문제
- 나머지 **15%**는 실력(유저 현재 수준)을 가장 정확하게 판단할 수 있는 수치
- 해당 변수를 어떤 기준으로 설정했는지, 목표치와 결과치가 얼마나 유사한지

# 문제 퀄리티

- 측정 기준을 어떻게 설정할 것인가?
- 문제 수준  측정(LLM이 문제 푸는 속도 기준?)
- 문제 수준이 점점 증가하는지(프롬프트 구조가 시간이 지남에 따라 점점 고도화 되어 가는지)

# 오답 분석 정확도

- 섬세한 목표 변수 설정이 핵심
- 특정 분류 키워드 변인이 포함된 문제 오답율 or 정답율이 설정한 변수% 이상/이하이면 해당 변인 문제 선정 가능성의 증/감을 결정!
(가중치 변경)
